# AUTO VIỆT — Showroom ô tô trực tuyến

Website tĩnh giới thiệu các mẫu ô tô và mô phỏng một số luồng mua hàng bằng HTML5, CSS3 và JavaScript.

## Chức năng
- Điều hướng đến các khu vực trong trang và menu responsive trên điện thoại.
- Lọc theo dòng xe và tìm kiếm tên xe.
- Thẻ sản phẩm lật mặt để xem thông số kỹ thuật.
- Chọn màu ngoại thất và phiên bản xe; giá thay đổi theo phiên bản.
- Giỏ xe: thêm sản phẩm, tăng/giảm số lượng, xóa xe và tính tổng giá tham khảo.
- Biểu mẫu yêu cầu tư vấn/đặt mua mô phỏng.
- Hiệu ứng Animate.css và AOS.

## Cấu trúc
- `index.html` — cấu trúc nội dung và biểu mẫu.
- `style.css` — giao diện, biến CSS, Flexbox/Grid và responsive.
- `script.js` — dữ liệu xe và các tương tác.
- `PROMPT_LOG.md` — nhật ký sử dụng AI và checklist kiểm thử.

## Chạy thử
Mở `index.html` bằng trình duyệt. Để kiểm tra chính xác hơn, có thể dùng tiện ích Live Server trong Visual Studio Code. Google Fonts, ảnh xe, Animate.css và AOS được tải từ Internet.

## Đưa lên GitHub Pages
1. Tải các file ở thư mục gốc này lên repository GitHub.
2. Vào **Settings → Pages**.
3. Chọn **Deploy from a branch**, branch `main`, folder `/ (root)`, rồi nhấn **Save**.
4. Chờ GitHub triển khai và mở URL Pages hiển thị trong phần Pages.

## Lưu ý
Đây là dự án học tập. Giá và thông tin xe chỉ mang tính minh họa. Giỏ hàng không lưu bền vững và biểu mẫu không gửi dữ liệu đến máy chủ; chưa có thanh toán hoặc đặt mua thật.
